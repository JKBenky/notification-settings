# 游戏社区通知设计（Game Community Notification Design）

一份关于游戏社区 App 通知体验的产品设计作答，附带一个可直接预览的通知设置页原型。

## 内容

- `作答.md` —— 三道题的完整作答：
  - 题目 1：好游快爆 / TapTap 的使用分析，以及「攻略新旧分不清」的改进方案
  - 题目 2：AI 总结攻略的一次好体验与一次坏体验
  - 题目 3：通知系统的设计——按「重要即时 / 社区互动 / 平台推广」分级的方案
- `通知设置页.html` —— 通知设置页的可交互原型（纯 HTML + CSS + JS，无需构建）

## 预览原型

直接用浏览器打开 `通知设置页.html` 即可，包含：

- 顶部「允许通知」总开关
- 重要即时：开测更新、@ 提醒、账号安全
- 社区互动：赞与评论合并、关注动态红点
- 平台推广：默认关闭、每周限 2 条、22:00–8:00 不发送
