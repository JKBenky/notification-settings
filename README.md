# 通知设置页设计（Notification Settings Design）

一个游戏社区 App 的通知设置页设计方案，附可交互原型。

## 在线预览

原型已通过 GitHub Pages 部署，直接访问：

👉 **https://jkbenky.github.io/notification-settings/**

（也可下载 `index.html` 用浏览器本地打开，效果相同。）

## 项目内容

- `通知设置设计方案.md` —— 设计文档：背景问题、三级通知分类方案、效果度量
- `index.html` —— 通知设置页可交互原型（纯 HTML/CSS/JS，无需构建）

## 方案要点

按紧急程度把通知分成三级：

- **重要即时**：账号安全、开测更新、@ 提醒
- **社区互动**：赞评合并、关注红点
- **平台推广**：默认静默、限频限时
